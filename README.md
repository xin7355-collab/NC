# Kinwell（舊名：家安康、NutriCore）：家庭健康與保障

家庭健康紀錄（體脂、體檢報告、手錶）、回診追蹤（App 判斷和醫師判斷並列）、病史、自我檢測、今年健檢與疫苗建議、營養師菜單、健身教練課表，加上保險（保單 AI 匯入＋防錯核對：🔴 錯誤／🟠 待核對／🟢 已核對分色並附「怎麼修正」、核保除外紀錄、保障缺口提醒、保障總覽、保障到幾歲時間軸、全家保障地圖、續保倒數、保費負擔、建議書比較、保險公司更新後重新匯入＋變更紀錄、理賠時間軸與時效、7 種保險 AI 提示詞）的單頁 App（iPhone 優先；電腦寬螢幕改成左側選單、內容兩欄、彈出視窗在右側）。家族史可以每位家人一筆（遺傳風險更準），用藥可以一種藥一筆（自動提醒交互作用）。設定在右上角 ⚙️。健康與保險資料只存在手機瀏覽器，不會上傳。

- **網址**：https://xin7355-collab.github.io/NC/
- **安裝**：iPhone Safari 開網址 → 分享 → 加入主畫面（避免 Safari 7 天清除資料），並定期在「⚙️ 設定 → 資料匯出匯入」匯出（全部或單一成員，可加密）。
- **改名後主畫面圖示**：已經加入主畫面的圖示名稱不會自己變。想換成「Kinwell」：先在 App 裡匯出備份，再刪掉舊圖示、重新加入主畫面（網址相同，資料通常還在；萬一被清掉就用備份匯回）。舊名的備份檔（jiaankang-…、nutricore-…）照樣可以匯入。
- **保險公司更新條款或保費**：只有保費變了 → 打開保單按「編輯」改保費；保額、附約、條款變了 → 用新文件再跑一次「用 AI 匯入保單」，選「用新資料更新這張」（理賠紀錄保留，舊版存進變更紀錄，可以復原），再對照新文件按「我已核對」。

## 菜色圖片
- **不用設定**：預設使用 [AI Horde](https://aihorde.net) 社群志工算力（免金鑰），排隊時間依當下人數約 1–10 分鐘。
- **想要 10 秒出圖**（需要電腦操作約 10 分鐘）：
  1. 註冊 Cloudflare（免費），在 My Profile → API Tokens 用「Workers AI」範本建立 Token，並記下帳戶 ID。
  2. 到 [script.google.com](https://script.google.com) 新增專案，貼上 `gas/Code.gs`；專案設定 → 指令碼屬性加入 `CF_ACCOUNT_ID`、`CF_API_TOKEN`（可再加 `DAILY_CAP`，預設每天 60 張，只算成功的張數）。
  3. 部署 → 新增部署作業 → 網頁應用程式（執行身分：我；存取權：所有人），把 `/exec` 網址貼到 App「我的 → 圖片後端」。
  4. 之後 `gas/Code.gs` 有更新時：貼上新程式 → 部署 → 管理部署作業 → 編輯 → 版本選「新版本」（網址不變）。
  - 出錯時 App 會直接說要去哪裡改（例如「還沒設定金鑰」「Token 無效」「網址要用 /exec 結尾」），設定類錯誤不會一直重試。
